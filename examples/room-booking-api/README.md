## Description
A small HTTP API that lets staff book meeting rooms for a time slot. The API checks for overlapping bookings and sends a confirmation email. The office front desk uses a separate client app, which is not part of this project.

## Run it
- Install: `npm install`
- Dev: `npm run dev` (starts the API on port 3000 with a local SQLite file)
- Test: `npm test`
- More commands added during development: see `docs/ARCHITECTURE.md`
